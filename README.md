# Portfolio

A single-page personal portfolio for Felix Gerberding, presented as a live, editable CSS file that styles itself as you read.

## Files

- `index.html` - markup and the editable `<style>` block
- `app.js` - small helper script
- `LICENSE.md` - license

## Run

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server
```
